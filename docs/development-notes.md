# 余光 · 星河

本地启动：`npm install`，然后 `npm run dev`，打开 http://127.0.0.1:4317/ 。生产构建 `npm run build`；测试 `npm test`。未配置 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_ANON_KEY` 时，记录只保存在本机浏览器；配置两者后，Supabase 是唯一的共享数据源，旧本地记录不会自动上传。生产直传与安全边界见[部署说明](docs/deployment.md)。

## 当前体验

Three.js 实时粒子和程序化云气构成 Claude 轮廓的星河。主画面仅保留底部居中的添加按钮，可拖动和缩放。填写停用日期后（注册日期可选），新星沿按记录 ID 稳定生成的直线轨迹快速划入，细短尾迹在约 1.85 秒内自然熄灭；落定后镜头用约 1.5 秒移向新星，停在距新星 12（移动端 14）个场景单位的近处，不播放落点爆闪。独立星悬停可预览在线时间与此刻余光，点击可读名字、留言和完整衰减信息。系统减少动态效果偏好下缩短飞行。

## 时间与亮度

账号存活天数为停用日期减注册日期加一天。初始亮度从 45% 至 100%，按存活天数的对数变化，一年以上达到上限。衰减半衰期为 `min(730, 30 + sqrt(存活天数) * 10)` 天；停用后的亮度按实际时间持续衰减，最低保留 3%。未填写注册日期的记录使用 100% 初始亮度和 120 天半衰期。

新记录以稳定 ID 分配空间坐标，重复 ID 更新同一颗星。未配置共享后端时记录保存在当前浏览器 localStorage；共享模式通过受限的 Pages API 写入 Supabase，浏览器只拥有读取权限。

## 历史基数

基础星群来自 Anthropic 透明度中心 Banned Accounts：2026 年 1—6 月约 11.4 million，官方页面更新于 2026-07-23。
来源：https://www.anthropic.com/transparency/system-trust-reporting

官方只披露汇总值，没有逐账号身份或封禁时间，历史光点因此没有个人故事和时间衰减。桌面采用 34,000 个、移动端采用 16,000 个固定采样光点的聚合表示，均对应约 1,140 万个账号，并非每个历史账号都绘制独立顶点。新增纪念记录与基数可能重叠，不相加宣称去重总量。

## 默认编号与闪烁

借鉴 IAU 的“目录缩写 + 序号”结构，项目星表使用 `AL 000001`。它属于本站虚拟星图，不对应官方登记的真实恒星。序号保存在记录中，重载及同 ID 更新时保持，旧记录自动补号。可不填别名，默认使用目录编号。本地模式在浏览器内补号；共享模式由数据库 identity 序列统一分配，并发写入也保持唯一。

新星落定后的闪烁振幅以 8 秒为衰减时间尺度，约 24 秒后降至初始额外振幅的 5%，保留轻微不规则闪烁；实际余光仍按账号存活时间计算。“减少动态效果”关闭闪烁。添加下一颗星时保留已有星的闪烁进度。

镜头渲染使用固定历史粒子数、降低像素倍率，移除多遍泛光后处理，并将星云噪声预渲染到纹理，避免镜头接近时每帧重复计算全屏多层噪声。

## 连续缩放与绘制

滚轮和触控板按输入累计对数目标距离，双指捏合使用同一条缩放路径；用与帧率无关的指数插值连续推进。视距范围为 0.25–600，近远裁剪为 0.005–1600，覆盖极近局部到整片星云。用户输入会接管正在播放的镜头动画。减少动态效果模式直接到达目标视距。

主场景直接绘制一次，不使用全屏后处理缓冲；DPR 上限为 1。历史光点和雾点的屏幕尺寸受限，贴近相机时淡出。账户星仍为独立可选取的记录，并保留到达后的渐弱闪烁。

## 开场演化

开场先用独立的轻量 Canvas 粒子层组成文字“你的 Claude 账号没有消失，只是从此不再回应，化作了星河里的一点光”。不显示加载提示；组成文字的星点按稳定随机顺序在约 2 秒内全部点亮，完整停留 1 秒，随后用先慢后快的三次方插值，在 1.7 秒内由文字散开并形成 Claude 轮廓。第 5.3–11.3 秒，固定的标志星群渐隐，固定的松散星云渐显；这段星云过渡不会移动星点。手机自动排成四行，以更大字号完整显示。

开场文字先于 Three.js 主模块独立播放，主模块后台加载；点亮与停留完成后，才初始化 WebGL。文字与 WebGL 共用同一套字形采样，首帧完成后移除开场层并接上文字到 Logo 的 GPU 过渡；复用原 Logo 粒子，常态绘制层不增加。个人记录的位置保持稳定。拖动、缩放或提交新星可接管开场。减少动态效果模式直接显示最终星云。

## 星星名片与分享

新星落定后，在星点旁显示名片：别名、默认星表编号、注册/停用日期、留言、星云局部 XYZ 坐标、slogan 和网站地址。坐标对应本站虚拟星云，不是现实恒星赤经赤纬。手机端让星点处于卡片上方，避免遮挡。收起后点击星星，可通过详情再次打开名片。

镜头落定后预生成 PNG 文件；点击分享时，支持文件分享的浏览器使用系统分享面板，由用户选择社交应用；不支持时下载图片。另提供复制文案。不会自动发帖。图片在浏览器本地生成，不上传截图或记录。生产构建可在 `.env.production.local` 用 `VITE_PUBLIC_SITE_URL` 指定分享图上的正式主页地址，未设置则使用当前页面地址；本地开发导出的网址仍是 localhost。共享模式的记录可跨浏览器出现在同一片星河中，但主页链接不包含或暴露个人记录 ID。

## 全景操作

默认全景进一步拉近（桌面视距 44、手机 74），提高星云首屏占比。添加按钮在粒子文字完成 Logo 形态后浮现；文字阶段保持隐藏且不可操作。缩放或旋转偏离默认视角、或跟随新星进入近景时，添加按钮左侧显示“恢复全景”。点击后收起名片并平滑恢复相机位置、中心目标与默认距离；恢复后按钮自动隐藏。

## 仅开发环境的调试与保存方案

只在 `npm run dev` 的本地 Vite 服务中，右下角“调试”会打开面板。分组包含文字/字体/粒子排版、开场节奏与插值器、星云/流星/闪烁、镜头速度/延迟/全景距离。编辑时只更新草稿；“应用并重播”会应用并收起面板，完整观看效果。重播使用当前已应用参数。所有时长以秒表示，插值器支持匀速、平滑进出、先慢后快（二次/三次）、先快后慢与慢快慢。

“保存方案”会应用草稿并写入当前浏览器 `afterlight-animation-preset-v1`；本地 Vite 开发服务还将同一方案保存到项目根目录 `debug-preset.json`。调好后告诉助手读取该文件，将参数固化到 `src/config.js` 的 `DEFAULT_CONFIG`。复制参数可导出完整 JSON。“恢复默认”只恢复动画参数，不会删除个人星星。

`/__afterlight/preset` 是仅由本地 Vite 开发服务提供的配置读写接口，有同源检查和请求大小限制。生产构建会在编译期去掉调试面板的动态导入、样式、快捷键和调试全局变量；没有 query-string 调试入口。调试草稿未应用时不会影响正在播放的场景。

入场计时从首帧完成绘制后开始，首帧着色器编译不消耗点亮或停留时间；页面进入后台时暂停。长帧最多完成当前阶段，不会一次跳过全部点亮后的停留阶段。面板保存的时长仍保持不变。
