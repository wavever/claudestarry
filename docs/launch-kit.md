## V2EX

### 推荐标题

做了个开源小网站：让被停用的 Claude 账号，在星河里留下一点余光

备选：用 Three.js 做了一片星河，给不再回应的 Claude 账号留个位置

### 正文：可直接复制

最近做了一个小项目，叫「Claude 余光 / Claude Starry」。

想法很简单：一个 Claude 账号不再回应之后，里面一起写过的代码、没做完的项目和聊过的事情，可能还会被人记住。我想给这些记忆做一个很轻的小仪式。

打开网站是一片可以旋转、缩放的粒子星河。你可以填写昵称和停用日期，也可以补上注册日期、留一句话。提交后，新星会沿着流星轨迹进入星河，落定后可以打开它的名片，保存成图片。

星河是共享的：其他打开页面的人也能实时看到新增的星星。界面支持中文和英文。

体验地址：https://claudestarry.pages.dev/

源码：https://github.com/wavever/claudestarry

技术上用了 Three.js、Vite、Supabase 和 Cloudflare Pages，代码采用 MIT 许可证。新增记录的校验和写入经过服务端接口，浏览器负责读取与实时展示。

这个项目不提供账号恢复或申诉服务，也不收集账号密码。填写的昵称、日期和留言会公开展示，用昵称就好。背景星尘是视觉表达，不代表站内真实提交人数。

目前更想听听大家对体验的意见：开场动画是否太长？手机上读名片方便吗？从流星落下到保存图片，这段流程有没有让你愿意停留一下？

如果给那个不再回应的账号留一句话，你会写什么？

不需要提供账号密码，昵称就好。留下的星星和文字会在共享星河里公开展示。

网站：claudestarry.pages.dev
